# 纯文字与少图材料：主动补足视觉表达

仅有文字也应形成图文并茂、内容饱满的成稿。先区分**缺表达载体**与**缺事实证据**：前者通过检索、论文配图、概念生图或原生绘图解决；后者保留未知，不用配图伪装成已完成的实验或成果。材料已齐全时只补真实缺口，不为丰富而重复找图。

## 从文字走到可用素材

1. 拆出每页的对象、主张、关系及支持它们的材料。把可视化机会标成场景、实体、结构、过程、比较或证据，不把每一段话简单改成一张卡片。
2. 在原有页面映射中补记素材任务：`页码｜表达目的｜视觉主体/画幅｜获取方式｜要支持的文字｜来源或提示词｜实际文件/状态`。同时选定整页拓扑和图片槽位，再搜索或生成与槽位匹配的素材。记录留在当前制作工作区，正常情况自行执行。
3. 按下表取得实际素材。能调用对应工具时，完成搜索、打开来源、下载/提取或生成；**不能只交搜索词、图片链接、生图提示词或一排占位框**。图片必须在制作工作区可用、经查看并嵌入PPT。
4. 将素材放回原有图文系统：同框标题—图像—可编辑标注—对应说明/结论，配原有题签、分组、侧栏及连接。视觉素材改变表达载体，不改变整篇的字体、配色、标题牌、框图语法与版式习惯。
5. 检查真实图、文献图、原创示意图和AI概念图的身份是否清楚，并逐页渲染检查实际效果。详细要求见文末。

## 内容到取图方式

| 文字内容/图的作用 | 优先方式 | 放入原有版式的方式 |
|---|---|---|
| 应用背景、工作环境、真实对象 | 搜索官方机构、实验室、厂商或可靠原始网页的真实场景/对象图；纯概念场景可生图 | T11场景—挑战—响应；真实图居主位，侧列痛点，底部收束 |
| 设备、试样、部件及空间关系 | 有指定对象时查对应型号/材料；无实物但有结构说明时画原生示意；复杂非证据性场景可生成 | T09工序—实体—属性；中央相框配编号定位和右侧说明 |
| 原理、机理、方法与已有研究 | 找原始论文的准确图和图注；简单机制可依据文字/文献重绘并注明改绘 | T06主图＋编号侧注，或T10双机制比较；图中部位与说明同编号 |
| 研究内容、总体架构、技术路线 | 按已给定的任务、输入输出、步骤和反馈画原生框图；实物或概念小图作为内部载体 | T01/T03/T04/T07；保留分组、层级、题签、共享条件和连接语义 |
| 方案比较、指标要求、组织与计划 | 原生比较矩阵、职责表、时间轴；仅在真实对象差异需要时补图 | T10/T16/T17；不为追求“有照片”破坏可比维度或时间比例 |
| 真实实验、测量、仿真与性能结果 | 使用本项目真实图和数据；外部论文仅作明确标注的文献对照；绝不用生图制造证据 | T12/T13；缺本项目结果时改为验证安排、评价维度或明确待测项 |
| 封面、愿景、抽象场景 | 可生成具有具体对象和作用关系的概念插画，或选择合适实景 | 服从所选家族封面和标题区；主标题与全部文字原生排版 |

不要求每页必须有照片。对象/背景页通常需要有意义的实景或概念图，路线/架构页需要有信息的框图，计划/比较页需要关系图表。整篇通过这些载体形成变化，避免全部变成文字卡片，也避免每页重复放同一张科技背景。

## 网页搜图：从页面主张找图

- 先把标题换成可见对象及需要的视角，例如“设备名称＋工作现场/结构/剖面/检测位置”；可并行试中文与英文的 `object + setup / cross section / application / schematic`，不只搜“某主题 科技 高清”。
- 使用可用的图片搜索或网页搜索工具发现候选。图片搜索结果是线索：打开原始页面核对主体、说明、发布机构和可获取的原图，不将搜索缩略图直接作为最终素材。
- 图必须支持附近的句子。类似外观不等于同一型号、材料、工况或算法；只能说明一般概念的图，应在图注中明确范围。一般场景不能证明本项目已有设备或成果。
- 比较少量合适候选的语义、清晰度、画幅与裁切余量，选最佳者；第一轮不合适时换具体对象词或原始来源，不无限搜图。仍无匹配素材时转到合适的原生示意或概念生图，并在记录中说明选择。
- 优先官方原图、开放许可或可明确引用的素材，保留出处及可见授权信息；署名本身不等于取得再分发许可。公开交付优先使用明确允许相应用途的素材，授权不清则换图或画原创示意，不去水印或绕过访问限制。
- 下载后实际打开文件，核对不是错误页/缩略图、方向与清晰度正确、主体未被裁掉。按最终槽位选择分辨率，避免用模糊小图放满半页；保留图片比例。

## 论文配图：先读图意，再提取图像

1. 按“对象/材料＋方法/现象＋示意或试验”检索原始论文，优先出版社页面、开放获取版本、作者/机构存档。用户给了指定论文时先核对该文；不能拿题名相似的另一张图替换。
2. 阅读摘要、相关段落与完整图注，确认图号、子图、变量、坐标、材料和工况，判断该图支持本页哪句话。只看搜索结果摘要或图片外观不足以采用。
3. 优先取出版社原图或PDF中的清晰图像；从PDF截取时先查看整页，再按准确图框裁切，保留必要图例、坐标、比例尺、子图标识及与含义有关的说明。需要时使用当前环境的PDF读取工具；不假设PDF一定能直接提取出完整矢量图。
4. 简单流程或原理图可按核实的关系重绘，保留原意并写“据…改绘”；复杂科学曲线和显微图尽量保持原图，不用AI补细节、重画成伪测量图、修改轴/数据或为统一配色改变科学色标。
5. 图下放简短归属，如“文献示例，作者，年份，Fig. X”；完整题名、来源URL/DOI、图号和用途放演讲者备注或素材记录。外部结果明确是文献对照，不能放在“本项目实验结果”下造成归属误解。

不可获取全文/原图时换可核对的开放版本或其他合适来源。仅靠摘要不能编出该论文的图、结论和精确数值；没有读到的内容保持未知。

## 生图：补概念和场景，并实际执行

适合概念场景、非证据性对象插画、应用愿景、无复杂文字的示意底图。不用于生成真实实验照片、显微结构、仿真云图、性能曲线或“已有成果”的替身。若请求本身是讲解某种现象，可画清楚标为概念的示意，不能以写实外观冒充观测。

需要位图插画时，使用当前可用的图像生成工具；若环境提供 `imagegen` 技能，先读其执行约定，优先内置生图路径。**写出提示词只是中间步骤**：调用工具→查看输出→按具体缺陷修正→将选定文件复制到当前制作工作区→嵌入PPT。不要预设所有环境都提供同一模型或接口。

提示词包含以下设计信息，按实际题材填写，不让模型替你决定整页版式：

```text
用途：中文科研汇报第X页的[场景/对象/概念]配图，属于[概念插画]，不作为实验结果。
主体与关系：[具体对象、数量、相互位置和动作；必须与已给文字一致]。
表达重点：[观众通过图应看懂的事实或概念]。
构图：适合[横向/竖向]图片槽位，[视角、主体位置、需要保留的边缘和局部]。
风格：[技术插画/朴素场景示意/概念渲染]，使用本篇家族的主蓝、浅底和少量强调色。
限制：不生成标题、中文标签、图例、坐标、数值、品牌标识、水印或PPT外框；这些在PPT里原生添加。
准确性：[必须保持的结构、对象数量、朝向；不能添加的部件或未经证实关系]。
```

例如，描述“多传感器采集设备状态”的文字，可以生成用于解释的设备与传感位置概念插画；传感器名称、数据流、分析步骤和输出放回可编辑框图。不要让模型自行增加具体设备型号、传感器数量、网络层数或准确率。

同一套插画统一视角、光照、笔触和背景。检查结构、数量和空间关系是否正确，是否出现伪文字、多余部件、炫光遮挡和与正文不符的细节。问题可修时做针对性迭代；质量不合格就换载体，不把“已生成”当作可用。

生图工具不可用或连续失败时，说明具体限制并继续完成可用的网页配图和原生示意；保留提示词供后续使用，不能声称图已生成。不自行转用需要新凭据、额外付费或用户未选择的API路径。外部检索也不可用时，依据文字画可编辑示意并标识；真正缺失的证据保留待补。用户明确要求实图的部分不能把示意图说成已满足。

## 把新素材装入原来的风格

- **先搭整页，再处理图片**：选原有T01–T17拓扑和组件组合，按槽位找图/生图；不因为拿到一张横图就把全篇统一改成左右分栏。
- **完整图文单元**：图片放在同框标题、轻影/细线外框或既有分组内，图注与结论紧邻；用编号、局部放大或引线说明具体部位。不能一张图漂在旁边，另外一侧堆全文。
- **原生框图始终承载逻辑**：标题、模块、数据圆柱、判断菱形、分支/汇聚和反馈连接可编辑。复杂概念底图可为位图，但不能生成带文字的整张流程图来代替原生结构。
- **保留最新细节偏好**：贴边题带与圆角外框共用轮廓；无填充虚线分组配居中有底色标题牌；字号和颜色按家族分层。图片不遮住这些边界和标题。
- **饱满来自信息**：优先补对象细节、关系、关键部位和解释，再调紧凑度。避免用无关装饰、重复图、巨大图标或编造实验数据填空；不要把一段文字强拆成四个虚假任务。

## 三种纯文字页面的落地示例

这些例子只说明表达方式，实际节点、数量与结论以当前任务为准。

| 输入文字 | 实际制作动作 | 整页结构与边界 |
|---|---|---|
| “设备运行环境复杂，需监测异常并安排检修” | 查合适的设备现场图；若只讲通用概念可生成概念插画；把已给挑战和响应画成关联模块 | T11：左场景相框—中挑战条—右响应模块—底部目的；一般场景不称为自有平台 |
| “采集数据，经预处理与分析得到状态判断” | 原生绘制输入、处理与输出；按文字决定数据组织图、小型对象示意或可引用的传感图 | T07：输入组—主链—输出，条件放共享侧栏；未给反馈关系不擅自闭环 |
| “计划通过试验比较两种方案，目前没有结果” | 画原生比较矩阵、试验安排及评价维度；必要时配明确标为参考的装置图 | T10＋验证安排；不画虚构性能柱图，不放文献曲线冒充本项目结果 |

## 素材记录与验收

在**当前PPT制作工作区**保留简短 `visual-assets.md`（等价表格/JSON也可）：素材ID、使用页码、角色、真实/文献/原创示意/AI概念类别、本地文件、来源页面与图号或提示词、使用范围和核对状态。网页素材的可见署名/许可信息一并记录；不将下载的图片、论文、生成图或项目内容回写技能目录与公开技能仓库。

成稿逐页检查：

- 每张图支持哪句话，来源和类别是否可辨；科学图的工况、图注、标尺与结论吻合。
- 图已实际嵌入，正常观看清楚，裁切与画幅合理；没有占位图、失效链接或将提示词当成已生成素材。
- 图文框、题签、原生标注、连接与结论形成整体，原有丰富版式和字体层级保留。
- 背景、方法、结构、比较和计划采用适合的视觉载体，整篇不会全部退化为同一种卡片或全图背景。
- 未经测量的性能与数量保持未知；补图提高理解与丰富度，不提高证据等级。

完成报告只说明实际采用的素材来源、已执行的生成/绘图、渲染检查及仍有的具体缺口。不把检索到候选、写出提示词或结构校验称为图文成稿验收。
