# 原生组件实现

分享版以文字配方为设计依据。使用当前演示文稿工具重建框、题签、连接和图注；图片、表格数据及公式内容来自本次任务。

## 单位与工具

参考文档按13.333×7.5英寸、字号pt说明；`scripts/component-kit.mjs`采用1280×720 CSS px画布，字号也是px。换算关系：1英寸=96 px，1 pt=4/3 px。不要将英寸坐标或pt字号直接当作px传入。

辅助代码适用于提供 `slides.add()`、`shapes.add()`、`shapes.connect()`、`images.add()` 等接口的 Artifact Tool 演示文稿对象。它不是独立PPT生成器，也不负责创建演示文稿、导出或渲染。没有这个工具时，按文档中的参数使用可用的PowerPoint制作工具；风格规则仍可独立使用。

辅助代码默认是weekly家族近似构件，不是整页模板，也不能替代其他家族的具体规则。

```js
// 此示例模块放在技能根目录；presentation 由当前制作工具提供。
import { panel, hanging, node, connect, header } from './scripts/component-kit.mjs';
const slide = presentation.slides.add();
header(slide, '本次标题', '本页主题', 1, { project: '当前项目', footer: '报告信息' });
hanging(slide, '实际子系统', 350, 180, 500, 280, { fill: 'none' });
const a = node(slide, '真实输入', 380, 250, 160, 70);
const b = node(slide, '处理步骤', 620, 250, 180, 70);
connect(slide, a, b);
```

这段代码仅演示连接与分组。实际整页先按 [整页搭法](composition-playbook.md) 明确关系，不应仅替换示例文字后交付。

## 关键实现约束

- **同一轮廓分色**：标题带和侧签优先在同一个原生 `roundRect`/`rect` 内通过相邻渐变断点形成两种实色。外框只描边一次，保留原生连接点。不得用直角片叠在圆角外框上露角或露白。
- **圆角按物理尺寸匹配**：不同尺寸相同圆角百分比可能产生不同半径。圆角归零时应真正变为矩形；大圆角与薄题带组合也要放大检查。
- **标题牌覆盖虚线**：无填充虚线分组使用居中蓝牌白字，标题牌本身盖住边线。额外白遮罩不得外露。
- **连接层级**：连接应位于外层背景之上、避开节点文字；按工具实际接口设置端点、箭头方向和绕线。移动节点后检查是否仍贴边，不把自由路径当作自动吸附节点。
- **真实嵌图**：图像字节必须进入导出文件。当前helper的 `image()` 接受本地PNG；其他图像格式应先转换或使用制作工具对应的正确MIME类型，不能只改后缀。
- **局部放大**：保留全图、定位区与共同尺度；放大只裁切真实图像，不补造科学细节。
- **分支合流**：多路数据先进入融合或汇聚节点，再通向输出；装饰箭头不能越过关键处理节点。
- **文字与字体**：模块标题、单位、数字串按真实字宽检查。中文字体不可用时替换并重排，不能依靠自动缩字掩盖问题。
- **原生表图**：轴、图例、单位和标签显式指定字体；图表须带实际数据。可编辑外框不意味着内部位图或原有公式已恢复。

导出后在实际查看环境中渲染，逐页检查接角、遮挡、箭头、换行、图像比例和科学标注。某个组件通过检查不等于整页视觉质量通过。
