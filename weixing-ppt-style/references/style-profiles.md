# 风格参数

以下参数是16:9页面的重建起点，不是固定容量或所有题材的统一模板。画布采用13.333×7.5英寸（960×540 pt）。页面坐标以左上角为原点，几何尺寸用英寸，字号与线宽用pt；换画幅时缩放几何，再复核实际可读性。

整篇选择一种家族。其他家族的构图可以借用，但页眉、字体、主色和标题层级需转换回来。先决定整页关系，再使用颜色和网格。

## 共同层级

主讲述句18–24 pt；模块条头、技术短句14–16 pt；图内细节通常12–14 pt。大成果主张可到28 pt，不能将这个字号推广到所有节点。中文与公式分开指定字体，Times New Roman适合数字、公式和部分英文标签。

外边距通常0.40–0.50；图片框内距约0.18–0.21；密集小节点净距可为0.04–0.10；普通分支净距约0.24–0.49。小间距服务于相关内容，不以同一个大间隔把整页拉成稀疏网格。

## weekly：白底科研与阶段汇报

- 主蓝 `#1F497D`，结构框与箭头 `#4472C4`，强调红 `#C00000`，白底与少量浅灰说明区。正文和坐标标签可用黑色。
- 主标题黑体加粗32–35 pt；“菱形＋主题”采用微软雅黑加粗24 pt；结论18–20 pt；流程节点14–16 pt。页眉中的机构信息只取本次材料，长标题与机构区应错开。
- 页眉约到y=0.85，正文从y≈0.95开始。页码附近留0.30–0.40的空间。短周报可省略目录或致谢，以场合和页数为准。
- 图文相框通常为0.75 pt浅灰边、白底，轻阴影可取4 pt模糊、3 pt距离、45°方向、约40%不透明度。阴影用于区分白底上的对象，不给所有小标签重复添加。
- 科学证据分组可用2.25 pt蓝色点划线、无填充、微圆角；子系统边界可用2 pt灰虚线。保留外分组和内部模块两层边界。
- 大阶段映射用透明尾部渐变到深蓝的块箭头；节点逻辑用约1.5 pt细灰连接线和三角端点。粗细箭头分别承担不同语义。
- 常用组合：图像＋图注＋局部标注、左右不等高证据组、工序＋实物＋属性区、网络＋下挂任务输出。

## research：章节导航型正式项目

- 主蓝 `#1D438F`，辅助蓝 `#4598D7`，浅底 `#EFF6FB` 或 `#DAEAF7`，关键红 `#C00000`，解释文字黑色。
- 中文使用微软雅黑。页标题可从28–30 pt起排；章节/课题横带24 pt，方向短题22 pt，主句20–22 pt，模块题头14–16 pt，模块正文约14 pt。成果主张可用28 pt，关键指标24 pt。
- 页眉为“章节号/章节名＋本页主题”，下接细蓝线。课题横带可置于y≈0.80，高约0.57，白字；左侧箭头编号区约占横带18%。
- 主体左右约0.45。有课题横带时从y≈1.55开始，无横带时约1.05开始。底部结论可占y≈6.65–7.10，并与页码、来源分开。
- 目录可用左31%蓝竖栏、右侧章节列表，当前项渐变高亮；章节数量来自本次大纲。
- 小模块多用0.75–1.25 pt主蓝实线、深蓝白字条头、浅蓝能力块、深蓝收束结论。父分支和子节点汇聚关系都要读得出来。
- 常用组合：需求—任务列—共同目标、双技术树、大架构图＋编号侧注、多条泳道＋贯穿评估栏、成果主张＋指标带＋证据矩阵。

## banner：深蓝横幅科技答辩

- 主蓝 `#003986`，模块深蓝 `#09327D`，连线 `#0070C0`，强调红 `#C00000`，浅底 `#D6ECFA`。
- 顶部深蓝横幅约占页面11%，标题微软雅黑加粗28 pt白字。正文区左右约0.42，从y≈1.10开始。
- 总述使用18–24 pt，模块节点14–16 pt，图内细节按观看距离决定。多层技术框图不能一键放大全部文字后删除结构。
- 正文以白底保证可读性；深蓝科技背景用于封面、结束或导航，使用当前任务可用的自制/授权素材或纯原生形状。
- 总述可用红侧签配白框；内部用直角或微圆角模块、浅色分区和粗渐变箭头。黄色只在深蓝背景上少量强调。
- 常用组合：场景—挑战—响应、分层支撑、嵌套模块、知识交互、平台与能力矩阵。

## classic：清浅蓝白申报

- 结构蓝 `#005DA2`，深蓝 `#002060`，强调红 `#C00000`，白底与非常浅的蓝灰底。
- 中文优先思源黑体系列；不可用时采用清晰黑体或微软雅黑，重新检查换行。标题36 pt，子标题22–24 pt，正文18–22 pt，技术标签14–16 pt。
- 主体从y≈1.0开始，左右约0.50。细蓝标题线、浅底分区、两栏/三栏、短竖签形成层次。
- 图框可用0.25–0.5 pt蓝细线、白底或2%–4%浅蓝不透明度填充；顶带可用约8%浅蓝。柔影只给外层容器，内部节点保持轻。
- 常用组合：折角总述、浅顶带图文框、同框双图、课题接口、肖像名牌、竖签风险矩阵。

## 起排网格

正文安全区可从B=(0.45,1.05,12.43,5.95)开始；有课题横带时改为B=(0.45,1.55,12.43,5.45)。有底部结论时再扣除0.55–0.75的高度。

| 内容结构 | 起排比例 | 关键约束 |
|---|---|---|
| 双对象比较 | 48% / 4% / 48% | 同一维度、基线与图像尺度 |
| 主图与侧注 | 64% / 3% / 33% | 编号和引线必须对应具体位置 |
| 现象证据与机制 | 38% / 4% / 58% | 图证与机制有明确关系 |
| 三并行任务 | 各31%，间隔3.5% | 只对同层任务等宽，内部内容可不同 |
| 三阶段流程 | 约30% / 35% / 30% | 余量给端口和关系箭头 |
| 人员与履历 | 22% / 4% / 74% | 照片不压倒任务相关信息 |
| 证据网格 | 2×2或2×3 | 对齐标尺、图注、坐标与裁切 |

这些比例服从内容关系。允许不等高与跨行区域，不把所有页面都排成同一种卡片网格。
