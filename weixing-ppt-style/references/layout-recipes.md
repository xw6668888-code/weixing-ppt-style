# 内容到版式配方

先根据本页内容角色选配方，再读 [整页搭法](composition-playbook.md) 与 [组件语法](component-grammar.md) 实施。比例是起排建议，不是固定模板。文字索引可用 `scripts/query_layouts.py` 检索。

| 内容 | 首选配方 | 关键实施点 |
|---|---|---|
| 封面 | 标题—身份—场合 | 题目按语义分2–3行；单位、日期取本次材料；长题目保留宽标题区 |
| 目录/转场 | 同一目录＋当前位置 | 当前章高亮，其余清楚弱化；章节数量来自本次大纲 |
| 背景/应用需求 | T11图像证据 | 上部需求短句，下部真实场景/样件组，底部由图支持的问题；单对象用大图＋侧注 |
| 研究现状/对象对比 | T10双机制比较 | 先确定2–4个共同维度，再放同基线图文；数据多则用表 |
| 挑战与响应 | T11场景—挑战—响应 | 问题与对策按实际关系连接，不强行一一对应 |
| 全项目研究思路 | T01需求—任务—目标 | 任务块保留编号、方法短句、图文和输出；依赖明确才连线 |
| 单项研究内容 | T02课题接口或T03双技术树 | 讲任务边界与预期输出；实现操作留给技术路线 |
| 技术路线 | T03、T07、T09 | 讲输入如何经过操作得到输出；保留实际步骤数量、验证与真实反馈 |
| 总体架构 | T04嵌套分层或T05共享评估 | 层级纵向、时间顺序横向；共享数据/标准/评估贯穿侧边或底部 |
| 总体目标 | 需求—总目标—分类产出 | 不使用无依据的大号百分比；与路线页的操作链区分 |
| 装置与试验 | T09工序/实物或T11图文框 | 保留工况、标尺、传感器、单位；图片证明实验条件或测量对象 |
| 多图证据 | T11、T12 | 主图区约70%–80%；按对象或工况关联图片、曲线和图注 |
| 定量验证 | T12科学证据 | 左方法/方程/参数，右预测与实测对照及误差，底部给证据支持的结论 |
| 指标要求与响应 | 蓝表头＋浅色隔行表 | 指标名称、要求/基线、目标/实测、评价方法；未测不能写成已满足 |
| 数据集或资源规模 | 对象示意＋统计条 | 左约45%对象/结构，右约50%规模、组成和划分；比例按真实计数计算 |
| 模型与多任务结果 | T08 | 输入、结构、输出头、后处理与邻近指标形成完整关系 |
| 成果交付 | T13或分类成果表 | 数量＋名称＋可交付说明；已完成与预期明确区分 |
| 应用示范与推广 | 平台输出—多场景或阶段链 | 共用接口只画一次；只有真实反馈才闭环 |
| 进度安排 | T17 | 条长和时间轴等比例；任务多时分工作包，不能删掉真实任务 |
| 分工/组织 | 职责表或汇报树 | 负责、参与、上下级分别表达，头像不能代替职责 |
| 团队与工作基础 | T15 | 肖像/身份、相关能力、证据；平台则用能力＋设备图组 |
| 风险与保障 | T16 | 类别、触发条件、影响、应对；风险等级据当前评估填写 |
| 经费 | 总额＋构成图＋精确表 | 来源、单位分配、费用构成分别核算，不能混作同一圈；多类别优先横条或表 |
| 周报进展 | 本周对象＋方法/结果证据 | 现象—限制/原因—下一步动作互相对应；短周报按需要省略预算、团队、目录 |
| 总结/结束 | 完成项或论证收束 | 结论数量来自内容；致谢按场合和页数决定，连续页码重新核对 |

只有文字或图像不足时，先按 [视觉内容补全](visual-enrichment.md) 为背景/对象页检索实图或生成概念图，为机理页核对论文配图或改绘，为路线/架构页绘制原生结构，再装入上述配方。不能只列素材需求或把全部页面改成流程框；真实结果缺失时改成验证安排，不编造试验或结论。固定页数时优先通过分层、精排和去重保留必要信息。
