# 组件语法

组件应把图、文字和关系组成清楚的视觉层次。先用 [整页搭法](composition-playbook.md) 选择拓扑，再选择组件，不能把装饰框随意铺成网格。

参数按13.333×7.5英寸页面给出，字号、线宽、阴影尺寸用pt。透明度描述统一采用**不透明度**：8%表示很淡。不同家族的外观应按 [风格参数](style-profiles.md) 调整。

## 轮廓与填充

| 角色 | 重建起点 | 使用方式 |
|---|---|---|
| 轻证据容器 | 0.25–0.5 pt蓝细线、微圆角、2%–4%浅蓝底 | 图与图注同框，容器浅于图片 |
| 标准白色图卡 | 0.5–0.75 pt细边、白底、轻柔影 | 用题带、图像与说明形成上下层 |
| 总述底框 | 细蓝线、很浅蓝底、宽而淡的影 | 只给外层总述，不给内部小节点重复大阴影 |
| 嵌套子模块 | 外框浅灰或蓝实线，内框灰虚线 | 用线型和浅底区分系统与内部节点 |
| 科学证据组 | 2–2.25 pt蓝点划线、无填充、微圆角 | 包住同一对象或同一证据链 |
| 成果主张牌 | 浅蓝细边、白底、少量柔光 | 配悬挂标题和独立指标带 |

贴顶标题带和侧边结论条必须与外框的**实际半径、位置和外缘**匹配。不同尺寸形状即使圆角百分比相同，实际圆弧也可能不同。优先使用一个原生矩形/圆角矩形内部硬边分色，使填充共享同一轮廓；或重建精确匹配的贴边形状。外缘只描一次，禁止直角突出、白缝与双边线。

无填充虚线外框默认放居中蓝底白字标题牌，牌自身遮住所跨边线。不要用白底无边框文字挖出一个白色缺口。必要遮线层须完全藏在标题牌后。

## 十二种组件

### B01 折角飘带与总述框

用浅底长框承载完整总述，短斜切题签向左、向上少量突出，下缘补深色小三角折角。可从题签宽2.4、高0.53，突出量0.14–0.26起排。标签约24 pt，正文按18–24 pt调整；关键短词使用独立红色文字片段。

顺序为底框→折角→渐变斜切带→白字标签→正文。文字增加时加高底框，不把短题签拉成半页。红色纵签是可选变体，同一篇固定一种主变体。

### B02 同框标题、图片与结论

外框顶部留约0.40–0.50高的题带，图像区左右内距约0.18–0.21。两张相关图共享同一个题签和结论时放在同一框内；它们之间的净距可约0.20。

大图框可从宽4.3、高3.4起排，其中图像约占内部高度75%，底部保留约0.7高的图注/结论区。说明应回答“是什么、看哪里、说明什么”中的必要问题。使用局部裁切时保持与原图的对应关系，保留标尺与关键部位。

### B03 图片底座与阶段箭头

照片或示意图下接同宽灰色/浅蓝底注，二者无缝贴合。多张图可形成同一场景组，再通过宽渐变箭头指向挑战、归纳或方案区。

粗箭头占据两区之间的完整通道，尾部渐隐、头部实色，关系词独立居中，例如“归纳”“映射”“约束”。节点步骤使用细线，不能把阶段映射与节点流程画成同一种线。

### B04 竖签矩阵

适用于风险、保障或分类措施。每格依次为短竖签、解释、细分隔、底部结论；竖签约占该格宽度12%，与框同高。竖排汉字保持正立逐字排列，不把整句旋转90°。

2×2单元可从宽约6、高约1.8起排，横纵间距约0.3。每格写真实触发条件、影响或依据及应对，不能只放四个口号。红色只强调关键处置或结论。

### B05 嵌套模块与悬挂题签

外边界上缘压一块有底色题签，框内再放子系统和小节点。标题牌可跨边约0.15–0.20，内部小节点净距可在0.04–0.10。

层叠顺序为外边界→子框→节点→内连接→标题牌与文字。标题和关联线未必与外框处于同一对象组，移动或复制时应检查整个视觉单元。无填充虚线子框同样用有底色居中标题牌。

### B06 编号任务列与双技术树

任务列包含外框、同轮廓蓝顶带、编号、方法短句和必要小图；多列上方共享需求框，下方共享目标框。每列可容纳5–6行不同角色的信息，避免重复改写同一段话。

双分支中，每支按“父题签→方法图文框→浅蓝能力块→统一输出”组织。子模块横距较小，父分叉线与底部汇聚线都保留。允许内部节点宽度不同，不能只剩两个无关系的大框。

### B07 编号侧注与技术泳道

大图约占主体64%，侧注约占33%。侧注用渐变题头、圆编号、局部小图与短说明；约1 pt虚线从大图对应位置引出，避免穿过主标签。

泳道采用左端角色签、内部图文步骤、约0.5 pt虚分隔和小箭头；多道右侧共用一个贯穿的评估栏。角色签可占泳道宽度约16%，道间净距约0.17。共享指标不在各道重复。

### B08 问题条与嵌套技术块

上部若干浅底短条列出现象或瓶颈，旁边安排直接相关的证据图；下部若干技术块分别包含蓝题头、处理对象、机制图和浅蓝短说明。

浅问题条高约0.5，技术条头高约0.4。问题与对策按真实关系对应，可以一对多或多对一。把完整视觉模块一起组织，不要只移动外框而留下独立图像和说明。

### B09 数据库、胶囊编号与能力矩阵

圆柱表示数据或知识，矩形表示处理或能力，胶囊编号用于平台或阶段短题。圆柱不能与算法节点混用形状而失去语义。

能力矩阵的列表示对象/平台，行表示能力层次。同一浅色横贯同一语义行，列间小桥签说明同层联系。小节点标签14 pt左右起排，矩阵必须有两个真实分类维度，不能把一列关键词伪装成矩阵。

### B10 成果主张牌与指标带

上部大白框配居中蓝色悬挂标题，主张约28 pt；下接中部浅蓝、两端渐隐的指标带，指标约24 pt，黑红混排。下部独立证据区包含图解、表格或结果矩阵。

顺序为主张→指标→证据。关键数字应能在下方图表找到依据，不能把同一成果重复写三遍。没有实验结果时使用方案与验证计划结构。

### B11 科学证据组与局部放大

按同一对象或同一条件，将照片、曲线、公式与结果表分组。点划线外框表达证据家族，图注与结论留在组内的明确区域。

局部放大由真实ROI、定位框或圈、引线、放大窗、尺寸/标尺组成。线端落在正确部位；放大窗只裁切已有图像，不生成新的科学细节。已有整张位图可整体使用，外围说明可编辑不代表内部图元可编辑。

### B12 肖像名牌、成果与进度

肖像和底部覆盖名牌同宽，照片框内距约0.2；右侧以浅题托分履历、能力和成果。只使用当前人物与真实证明材料。装饰应服务于身份层级，不能替代信息。

进度用原生表式甘特或分组条图，时间轴等比例，虚线区分阶段。条高可从0.24、行步长0.28–0.35起排，再按字数调整。任务多时按工作包分区，不能为了固定几条而删掉真实任务。

## 连接语法

| 关系 | 表达 | 检查 |
|---|---|---|
| 大阶段映射或因果 | 宽渐变块箭头＋独立关系词 | 保留通道、方向与阶段区别 |
| 单向流程 | 1.5–2 pt原生直线或肘形连接符 | 吸附节点端口，避开文字 |
| 多源汇入 | 肘形线进入同一融合节点 | 汇入与输出的顺序完整 |
| 反馈或回路 | 约2–2.25 pt强调线，沿外侧绕行 | 只有真实反馈才闭环 |
| 双向接口 | 两个分置的小箭头 | 明确两种方向的语义 |
| 局部解释 | 约1 pt虚线＋匹配编号 | 不伪装为数据流 |
| 跨多个节点的关联 | 外绕括号或曲线 | 手工图形须在节点移动后重定位 |
| 图像局部放大 | ROI定位线与真实放大窗 | 裁切、尺度及线端对应 |

粗块箭头、细实线、虚线引注可以同页共存，各自承担不同语义。移动节点后检查连接是否仍吸附；不要用没有连接点的自由路径替换需要接线的原生节点。

## 信息密度与编辑边界

用外层大标题→模块题签→内部节点→图注/指标建立字号层级。红色通常只占一个短词或数值，不整段染红。保留有用的框、浅底和注释；内容不足时允许空白，不填造结果。

框、文字、表格和主要连接优先原生可编辑。科学照片、扫描图和复杂位图按实际素材保留图片属性。把整页截图贴到幻灯片上不能算完成可编辑制作。
